Student Panel — Database ER Diagram

The 16 tables of the single-operator (PGlite) build. PK = primary key, FK = foreign key, UK = unique. Generated from server/src/db/migrations/001–008.

How to read this:
  • Each box is a table; each line inside is a column — data type on the left, column name next, key tag last.
  • A connector between two tables is a foreign key (a link the database enforces). The crow's-foot end means "many"; a single bar (|) means "one"; a circle (o) means "optional / zero".
  • target (XOR) links: an assignment row points at either a group or a student — exactly one, never both.
  • student_field_definitions has no connector on purpose: a student's values live in students.extra (JSONB) keyed by a definition's id — a logical link, not a database foreign key.
  • The five boxes with no connectors (settings, preferences, saved_views, user_sessions, audit_log) are standalone "plumbing".
To print: print in landscape with "Fit to page" (A3 gives the most readable result).
